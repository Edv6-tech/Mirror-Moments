# Local sample images

These samples are stored in the app so preset selection and thumbnails work without depending on a third-party image host at runtime.

- Fashion, hair, footwear, handbags, jewellery, and portrait samples were originally selected from Unsplash and used as remote references in the project.
- Makeup preset thumbnails came from the existing YouCam makeup pattern catalog CDN references.
- `sample-hand.jpg` is the existing YouCam demo hand sample used by the nail and ring previews.

The source URLs are no longer requested by the application. These assets are example images for preview and virtual try-on demos, not product listings.
